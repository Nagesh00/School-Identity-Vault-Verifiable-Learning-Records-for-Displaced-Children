## 2. Application Form Responses

**Platform**: ImagineCup.com
**Deadline**: January 9, 2026

**Required Responses** (Address each judging criterion):

### Question 1: Problem Definition
**What**:
- How clearly has the team defined a unique and compelling problem?
- What makes this problem urgent and original?
- Who are your identified customer segments?

**School Identity Vault Response Template**:
```
The Problem: 258 million children are displaced globally due to refugee 
crises, migration, and disasters. These children lose their educational 
records and cannot prove their learning achievements, forcing them to 
repeat grades or be excluded from school systems entirely.

Evidence:
- UNICEF reports on education in emergencies
- Statistics on displaced children globally
- Interview data showing education barriers

Customer Segments:
1. Families/NGOs (document uploaders)
2. Schools (verifiers in receiving countries)
3. Education ministries (integration partners)
4. Humanitarian agencies (UNICEF, Red Cross)

Why Us: Our team has experience in [education/technology/humanitarian 
work], positioning us uniquely to understand both the problem and 
technology solution.
```

### Question 2: Customer Validation
**What**:
- Have you engaged with real users/customers to validate assumptions?
- What evidence of user engagement do you have?
- How has feedback informed iterations?

**School Identity Vault Response Template**:
```
Validation Activities:
1. User interviews with 10 refugee families
   - Pain points: proving education level
   - Document loss frequency: 80%+
   - Interest in solution: [%]

2. NGO partnership discussions
   - [Organization name] interested in piloting
   - Schools in [region] requested access
   - Feedback: [specific improvements requested]

3. Iterative feedback:
   - Initial design → [feedback] → Current version
   - Example: Added multi-language support based on user requests
   - Example: Simplified upload flow after user testing

Metrics:
- User satisfaction score: [X/10]
- Time to verify profile: [X minutes]
- Successful verification rate: [X%]
```

### Question 3: Microsoft Technology Usage
**What**:
- How meaningfully have you leveraged Microsoft AI services?
- How core are these services to your value proposition?
- Technical summary + demo showing AI in action

**School Identity Vault Response Template**:
```
Microsoft AI Services (CORE to solution):

1. Azure Computer Vision API
   - Extracts text from low-quality images
   - Supports multiple languages and scripts
   - Essential because: Without OCR, can't read refugee documents
   
2. Azure Language Service
   - Parses education-specific entities (grades, subjects, dates)
   - Extracts curriculum information
   - Essential because: Converts raw text to structured data

3. Azure OpenAI
   - Generates human-readable profile summaries
   - Maps foreign curriculum to local equivalents
   - Essential because: Makes data actionable for schools

4. Azure Machine Learning
   - Calculates confidence scores for each component
   - Identifies conflicting information across documents
   - Essential because: Schools need to trust the verification

Why Microsoft:
- Most reliable multi-language OCR capability
- Enterprise-grade security (important for refugee data)
- Comprehensive AI portfolio covering our entire pipeline
- Azure integration with existing government/school systems

Demo: [Link to demo video showing each service in action]
Architecture: [Link to architecture diagram]
```
